# Sistema de Inicio de Sesión

## Descripción

Este proyecto consiste en una interfaz web de **Inicio de Sesión**, donde el usuario puede ingresar su correo electrónico y contraseña para acceder al sistema.

El proyecto fue realizado utilizando **HTML y CSS**.

## Requerimiento funcional

**Inicio de sesión:**
El sistema deberá leer y verificar los datos del usuario, específicamente el correo electrónico y la contraseña, dentro de la interfaz de inicio de sesión para permitir el ingreso en la página web.

## Funcionalidades

- Permite ingresar un correo electrónico.
- Permite ingresar una contraseña.
- Cuenta con un botón para iniciar sesión.
- Valida que los campos sean obligatorios.
- Presenta una interfaz sencilla y fácil de utilizar.

## Tecnologías utilizadas

- HTML5
- CSS

## Funcionamiento

1. El usuario abre la página de inicio de sesión.
2. Ingresa su correo electrónico.
3. Ingresa su contraseña.
4. Presiona el botón **Iniciar sesión**.
5. Los campos son revisados para comprobar que tengan información.

> Nota: En esta versión únicamente se encuentra desarrollada la interfaz. La verificación real de las credenciales puede implementarse posteriormente mediante JavaScript y una base de datos.
